2026-10-06 用户反馈复核：修复前新增回归实际复现缩放从 **156.25% 降到约 73.04%**。原因是首次选择节点时详情区出现，改变画布高度，原 `ResizeObserver` 无条件执行“适配视图”。现改为仅首次可见时自动适配，进入／退出全屏、切换阅读模式和主动适配仍按新尺寸调整；节点详情和普通尺寸变化不重置阅读状态。实测鼠标滚轮覆盖像素单位，行／页单位用可取消的浏览器事件补充检查，不宣称已经实测所有 Firefox 设备。此次反馈修改仅涉及前端，后端 194 项为前一阶段完整回归结果。

SVG 校验包括：节点数、节点完整标题、可见文字、首尾边界、所有节点之间不重叠、子节点位于父节点右侧；在浏览器中实际测量文字包围盒，确认其没有超出卡片。特殊字符和 Emoji 保留，标签不会被当作 SVG 脚本执行。实际 PNG 和全屏截图已查看，另检查图片首尾局部的中文、英文、节点边界和长文字末尾。

## 4. 图片预算与验证边界

PNG 优先 3 倍，必要时选择 2 倍，提示中显示实际分辨率与节点数。单边限制 16,384 像素，总量限制 32,000,000 像素。两档均超限时提示下载 SVG，保留完整内容，不生成裁切图片或降低到模糊缩略图。

SVG 使用系统中文字体回退列表，PNG 已将文字绘制为像素。本次实测浏览器为 Windows Edge；未宣称所有移动设备、浏览器或操作系统的原生全屏与字体表现已验证。真实平台持续可用性、抖音无字幕处理和 60～120 分钟视频知识质量沿用原有报告边界。

## 5. 用户验收

先停止旧后端，再在项目根目录运行：

```powershell
.\start-local.ps1 -Port 8181 -UseFirefoxSubtitleSession
```

在学习历史中打开已有记录，无需重新调用模型：

1. **思维导图**：确认分支向右展开，长节点更宽、短节点紧凑；进入全屏并放大，首次展开章节、查看长节点时不自动缩小；验证滚轮上下、Shift＋滚轮横向、Ctrl＋滚轮缩放；用 Escape 退出。
2. **图片下载**：保持某些章节折叠，分别下载 PNG 和 SVG；放大查看长文字和最后一个章节，确认全部保留且清晰。
3. **字幕原文**：搜索或切到第二页，分别下载 SRT、TXT；打开文件检查首尾字幕、当前语言、中文和时间戳。

上述体验确认后，本次功能可验收；无需用户重新生成摘要或重复下载视频。
