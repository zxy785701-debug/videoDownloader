# 视频信息与总结同屏：开发及验收报告

日期：2026-10-07。用户已回复“按推荐方案开发”，确认 [页内双栏方案](UNIFIED_VIDEO_WORKSPACE_PLAN.md)。开发和自动验证已完成，**人工验收待用户确认**。

## 实现结果

- 桌面左侧为封面、标题、来源、时长、紧凑清晰度选择和下载；下载操作固定在左栏底部，信息与右侧学习内容分别滚动。手机上下排列，使用页面自然竖向滚动。
- 点击一次“解析视频”后显示视频信息，并获取支持平台的字幕。自动总结默认开启，偏好保存在浏览器；提交时固定链接和开关选择。关闭开关仍可获取、搜索和下载字幕，也可手动生成摘要。
- 摘要、字幕原文、思维导图和视频问答保留原功能；学习记录改为按需打开的弹窗。旧 `#learn`、`#learn/{id}` 和返回首页入口继续可用。
- 字幕成功后由后台自动接续流式摘要。关闭网页、刷新和切换页签不打断已提交链路；服务停止或重启后需手动重试。
- 已保存摘要直接复用，不因模型配置改变而自动重写。现有活动任务接回原任务；失败、中断的链路和语言切换不自动调用模型。
- 无字幕、访问受阻、超限、模型未配置、AI 不支持的平台、模型失败等情况不影响同屏下载操作。
- 下载期间锁定新链接和会改变当前视频的历史操作，学习页签及问答仍可用；下载状态暂时断线自动恢复，任务过期后解除锁定并允许重试。

## 人工验收

正式地址：<http://127.0.0.1:8000>。使用自己的配置和本机记录；测试完成后可按原方式启动 `./start-local.ps1`，字幕 Firefox 会话仍由原设置或显式参数控制。

1. 粘贴一个有有效字幕的视频，保持自动总结开启，点击“解析视频”：视频信息与摘要状态同屏，字幕完成后自动总结；可同时准备下载。
2. 查看摘要、字幕、导图和问答；打开本机记录，确认已有摘要直接显示；刷新不会自动重新生成。
3. 关闭自动总结并解析另一个视频：只获取信息和字幕，手动生成按钮可用；手机上下阅读、页面可正常滚动。

自动总结及手动生成／追问使用现有 DeepSeek 账户。此前成功的平台或模型样例属于历史证据，本次未新增真实付费验证。最后一轮摘要浏览器回归曾出现一次本机 HTTP 连接重置；服务仍健康，使用新隔离实例重跑 14 项全部通过。若人工验收发现问题，请提供链接、窗口尺寸和操作顺序以便复现。
