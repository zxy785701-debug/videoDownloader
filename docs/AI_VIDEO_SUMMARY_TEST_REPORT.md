### 真实内容核对与用量

使用 `deepseek-flash`，最终摘要提示词版本为 `video-learning-3`。生成结果明确区分讲者观点与已核实事实；禁止自行补充地点、因果和混合时间线，并给出篇幅指引，降低 JSON 输出截断概率。若仍截断或引用非法，程序判定失败，不将残缺内容标为成功。重新生成失败时保留上一次成功摘要。

两条摘要抽查了至少 10 处原文引用，核对内容和实际时间戳。引用 ID 有效不等于结论语义正确：部分章节引用落在话题开头，完整依据需结合相邻字幕阅读；尚不能据此声称所有结论准确。平台自动字幕中的人名、术语也可能有识别误差。

YouTube 真实问答逐条核对，共 **8/8 符合预期**：

| 问题范围 | 核对结果 |
| --- | --- |
| 出发城市、隐形眼镜、外套颜色、纽约演出回忆、片尾礼物 | 5 个有依据问题均回答，并提供字幕引用 |
| 追问具体成员的礼物 | 回答对应礼物并引用原文，连续对话可用 |
| 拍摄相机型号与参数 | 字幕没有提供，返回依据不足 |
| 最后一帧像素 RGB | 需要画面信息，返回依据不足 |

这只是本次 8 个问题的样例结果，不是问答总体准确率结论。实际调用用量包含前期生成、输出修复、失败后重试和问答，不能当成单次最终摘要用量：

| 记录 | 已返回用量的请求数 | 输入 tokens | 输出 tokens | 输入缓存命中 tokens |
| --- | ---: | ---: | ---: | ---: |
| B 站 | 4 | 35,401 | 13,476 | 26,112 |
| YouTube | 12 | 159,257 | 12,810 | 130,688 |
| 合计 | 16 | 194,658 | 26,286 | 156,800 |

缓存命中是输入的一部分，不能再与输入相加。界面只统计服务端已经返回并保存的用量，未返回的请求不计入该统计；实际费用以 DeepSeek 账单为准。

## 6. 本机配置与人工验收

本机密钥已经配置在被 Git 忽略的 `.env`，`.env.example` 的密钥项已留空。检查确认源码、文档、前端构建与学习数据库未包含该密钥。后端启动只读取学习配置白名单，不加载 `.env` 中的下载配置，不将密钥发给前端。

本轮模拟测试服务已停止，真实验收服务仍在 `http://127.0.0.1:8181` 运行，原有 8000 端口下载进程未终止。直接打开验收页面即可，不必再启动同端口服务；以后停止并重启时，在项目根目录运行：

```powershell
.\start-local.ps1 -Port 8181 -UseFirefoxSubtitleSession
```

打开 `http://127.0.0.1:8181` → AI 学习，可查看 `backend/data/learning.sqlite3` 中已有的真实摘要、字幕、导图和对话。摘要与问答会产生账号用量；查看已有内容不会重新生成。更改 `.env` 后需重启服务，环境变量优先于文件。若选择临时隐藏输入，可附加 `-AskDeepSeekKey`；脚本退出时恢复相关进程环境设置。
