# 抖音 AI 总结

本次补齐公开抖音普通视频的学习入口，沿用现有云端 ASR、预算、缓存、后台任务、摘要、导图、问答和字幕导出。没有增加推理模型、依赖、端口或数据库迁移。

2026-10-11 的云端间歇空页证据、有限退避和免费诊断工具见 [抖音云端诊断](DOUYIN_CLOUD_DIAGNOSTICS.md)；ASR 小时限额已区分普通账号 3 次、有效会员 10 次，见 [ASR 配置](ASR_FALLBACK.md#asr-小时限额与会员额度)。本页以下真实端到端结果保留原验收范围，不代表本次重复付费验证或服务器端到端通过。

## 处理流程

1. 标准视频链接、精选页 `modal_id` 和短分享链接继续使用现有抖音分享页适配器。
2. 匿名模式从同一作品的分享页读取明确提供的字幕资源，复用现有 SRT/VTT/JSON 解析和时间轴校验。描述、话题、评论和背景音乐信息不能代替字幕。
3. 没有字幕、字幕为空或不可获取时，进入现有 Paraformer-v2 兜底。显式启用的 Firefox 字幕登录会话继续保留原流程，B 站 Cookie 配置和 YouTube 配置不变。
4. 重新解析有时效的视频地址，使用移动端请求头、流式临时下载和最多 4 个标准 HTTPS 同作品备用地址。当前抖音适配器通常提供合并音视频，必要时在大小上限内临时下载视频，再用 FFmpeg 提取音轨；不使用可能只有背景音乐的 `music.play_url`。
5. 原有独立短时进程将音轨转换为 16 kHz、单声道 FLAC，默认单线程；然后由既有 ASR 服务上传私有 OSS、签名、提交、轮询、保存字幕并清理资源。
6. 有效字幕进入原有 AI 学习接口。重复视频复用学习记录，重复音频和参数复用 ASR 缓存；已提交或状态不明的付费任务继续查询/阻止重提。

图集、直播、私密和已删除作品不在范围内。平台拒绝访问不能通过 ASR 绕过；只返回明确错误，不编造转录。媒体地址仍要求标准公网 HTTPS，未放宽内网、非标准端口或任意 FFmpeg 网络访问。

## 配置和部署

沿用 [ASR_FALLBACK.md](ASR_FALLBACK.md) 的服务端配置，不新增环境变量，不在网页填写云端密钥：

- `ASR_ENABLED=true`、`ASR_PROVIDER=aliyun_paraformer`、`ASR_MODEL=paraformer-v2`。
- 百炼北京地域、私有 OSS 及既有服务端凭证配置。ASR 参数和阿里云凭证现已支持项目根目录 `.env`；进程环境变量仍优先，修改后需重启自己的后端。
- 现有 DeepSeek 服务端配置；没有 LLM 配置时不能生成 AI 摘要。
- 默认 ASR 最长 60 分钟、单任务、单 FFmpeg 线程、下载 256 MiB、FLAC 120 MiB、应用预算 10 元/月。预算和费率配置沿用原逻辑，不替代云厂商账单限制。
- 云端通常使用 `VIDEO_LEARNING_FIREFOX_SESSION=0`；本机已明确启用的 Firefox 会话不必改动。未启用语音转录时，抖音无字幕视频仍不能总结。

本次只做本地开发，不修改宝塔或真实配置。需要部署时，由管理员更新代码、构建前端 `npm run build --prefix frontend`、重启现有 8000 后端。现有 Nginx、8010 会员服务和 SSH 隧道无需新增配置。

## 一次真实付费验收

cd D:\nbproject\videoDownloader

执行前需要前端构建完成、已有本地端到端工具依赖、Node/Playwright/Edge 可用、端口 8000 空闲。脚本遇到占用时停止，不能自动停止或重启现有服务。没有配置密钥时只提示变量名称，不输出密钥值；不需要截图或发送凭证。

脚本检查真实 OSS 私有 ACL、未签名访问 403、签名 HTTPS、音频读回一致、云端任务与时间轴、删除对象、摘要与导图、重复缓存及导出。浏览器只读取结果和重新解析免费元信息，不能触发付费写入。问答仅检查空状态/页面恢复；不会额外调用付费问答。真实问答生成由 Mock 回归覆盖，不能描述为本次真实验收。
