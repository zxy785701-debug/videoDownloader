# SaveAny 真实 B 站 ASR 端到端验收报告

验收日期：2026-10-10。本机 Windows，使用用户已配置凭证的 PowerShell；未部署、重启或修改宝塔生产服务。结论：**指定样例的登录原生字幕链路和匿名 ASR 兜底链路均通过**。这不等于所有视频、其他平台或目标服务器均通过真实验收。

## 样例与证据范围

用户指定同一个视频：[BV1HnSVY6Eho](https://www.bilibili.com/video/BV1HnSVY6Eho/)，标题“档字幕逆天方法”，解析时长 108.22 秒。没有另选付费视频。

- 登录组：保持既有 Firefox 字幕会话代码，测试子进程启用本机会话。真实获取平台自动字幕，`source=native_subtitle`、`provider=bilibili`。
- 匿名组：仅在测试子进程关闭 Firefox 会话，原生字幕实际返回 `CAPTIONS_ACCESS_REQUIRED`，由真实后台任务自动进入 ASR；没有手工注入字幕或强制替换原生结果。
- 两组均使用 `BILIBILI_METADATA_SOURCE=api`，真实调用现有解析、学习、总结、问答和导出 API。真实 OSS、Paraformer 和 DeepSeek 请求没有 Mock。
- 学习数据库分组隔离，但两组共用第一次真实测试的 `.local/asr-live-first/asr.sqlite3`。既有云任务、缓存、费用记录和 LLM 提交意图账本均保留。
- 浏览器检查访问真实服务和已生成的结果，允许同一视频的免费元信息解析，阻止其他写入；没有在浏览器中再次调用模型。用户提交及后台生成由真实 API 驱动，浏览器随后验证结果与交互。

最终成功证据目录：`.local/asr-live-first/bilibili-e2e/20261010-133238-f7e6e599/`，包括两组 `report.json`、`browser-report.json`、`transcript.json`、`summary.json`、`messages.json`、导出文件、页面截图及 `memory.csv`。目录根部 `verification.json` 为随后独立进行的只读结构、引用、账本及临时目录核验；它没有发起网络请求。

首次登录组报告保留在 `.local/asr-live-first/bilibili-e2e/20261010-132746-d30fe050/native/`。所有本地报告和数据库位于 Git 忽略目录；公开文档不复制密钥、Cookie、完整签名 URL 或完整云任务 ID。

测试运行器的 `asr.checks` 复用了短音频测试的字段，其中 `task_id_saved`、`subtitle_valid`、`local_tmp_cleaned`、`repeat_cache_hit` 在本轮原始报告为 null，不能解释成已检查。任务 ID 与字幕由运行器的独立检查及 `verification.json` 验证，本地临时清理由后者验证；本轮没有再次请求匿名视频验证 ASR 缓存命中。此前 20 秒真实音频测试已验证持久缓存；本轮真实验证了登录记录、总结和问答的复用。

代码优先选择音频直链，FFmpeg 配置为单线程、单声道 16kHz FLAC，以文件及分块方式处理。本轮报告没有单独记录源媒体格式、音频字节数和 FFmpeg 线程运行轨迹，不能仅据报告断言本次完全没有下载视频轨道；单线程和优先音频策略另由代码及本地回归覆盖。
