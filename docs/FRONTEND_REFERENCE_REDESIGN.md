# 前端参考设计改版与验收

更新日期：2026-10-08。用户确认四张图片作为新设计参考：白底蓝色、圆角输入框、简洁账号弹窗和双会员卡片。当前方案已实现并完成自动验证，视觉与实际操作的人工验收待用户确认。

## 已实现

- 首页采用蓝色图标、SaveAny 品牌、黑蓝标题、胶囊输入区和平台标签；下方提供真实功能、具体使用教程、免费／VIP 双卡和中英文公开教程入口。
- 注册、登录、验证及找回密码使用紧凑表单；未登录时顶部入口按最新用户要求显示“登录”，登录窗只显示账号操作，购买方案和额度集中在登录后的会员中心。密码默认隐藏，支持显示／隐藏；切换表单和关闭弹窗时恢复隐藏状态。
- 登录后用头像下拉菜单查看邮箱、会员状态和到期时间，进入会员中心或退出登录。会员状态和剩余额度仍以服务端响应为准；不增加第二套账号状态请求。
- 免费／VIP 卡片由首页与会员中心共用。首页“查看会员方案”只打开账号窗口；登录后点击“购买会员”才调用原支付接口。原订单续付、等待确认、退款提示与支付页备用链接保留；已生效会员不能重复购买。
- 解析后保留页内双栏：左侧视频信息与固定下载操作，右侧摘要、字幕、导图和问答。调整边框、圆角和标签样式，首页介绍区域让位给工作区。
- 桌面双卡、手机单卡；320px 页面和账号弹窗没有横向溢出。保留系统深色主题与减少动态效果的设置；弹窗保持键盘焦点约束和关闭后焦点恢复，下拉菜单支持 Escape、点击外部关闭及焦点返回头像。

## 业务规则与边界

参考图只决定视觉。文案沿用此前用户确认的规则：下载不限量，免费账号每天新生成 AI 总结 3 次，会员 30 次；¥19.90 一次购买 30 天、不自动续费，北京时间零点重置。失败释放预留、复用和导出不扣次数、重新生成扣一次，模型费用仍由本机 DeepSeek API Key 持有人承担。

没有采用参考图中的 ¥9.9、无限 AI 总结、1800+ 平台、限时优惠、专属客服或有效期内续费承诺。密码继续要求 12～128 个字符；当前注册无需邮箱验证，以后仍可通过既有服务配置启用验证。找回密码沿用原邮件流程，本轮没有增加或配置邮件服务。

本轮没有修改后端、支付校验、摘要额度或模型调用代码，没有增加前端依赖或外部图片／字体。公开 SEO／GEO 静态介绍站继续使用原构建和内容；本轮改版针对本机工作区。

## 人工验收

在原地址 `http://127.0.0.1:8000/` 按 Ctrl+F5 刷新：

1. 查看首页及“套餐价格”，确认标题、输入区、双卡、价格和权益展示符合参考方向。
2. 打开“登录”，切换注册、登录和找回密码，检查输入、密码显隐、错误提示及关闭操作。
3. 登录已有账号，从头像菜单进入会员中心，核对实际额度与到期时间；开通操作仍按既有 Stripe 沙盒教程执行。
4. 解析一条原有视频，检查左侧下载与右侧摘要的同屏阅读、导出和问答；手机检查单列布局与弹窗滚动。

账号与支付仍处于原本机测试环境。人工验收尚未完成，不将自动验证标记为用户已验收。
