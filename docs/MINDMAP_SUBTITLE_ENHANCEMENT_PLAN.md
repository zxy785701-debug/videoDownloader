## 3. 推荐功能范围

### 3.1 全屏阅读

在导图工具栏新增“全屏阅读”，提供全屏专注阅读界面，保留缩放、拖动、适配、节点折叠、完整文字详情和字幕定位。显示“退出全屏”，支持 Escape 退出并恢复操作焦点。

优先使用浏览器全屏能力；不可用或被拒绝时使用占满页面的阅读界面。全屏优先保证画布空间，工具栏保持可见；节点详情可滚动，避免长文字挤掉画布。进入或退出后重新计算画布尺寸，保留原记录和折叠状态。窄屏同样提供入口，同时保留树形列表阅读。

2026-10-06 用户反馈后确认增加滚轮操作：滚轮上下移动，Shift＋滚轮横向移动，Ctrl＋滚轮围绕鼠标位置缩放；触控板横向滚动同样支持。滚轮仅在导图画布内接管，其他区域继续正常滚动。首次出现节点详情、展开／折叠和窗口尺寸变化时保留当前缩放与位置，用户可主动点击“适配视图”重新居中。

离开导图、定位字幕、切换记录或关闭学习工作区时清理全屏状态，恢复页面操作，避免锁住滚动或残留遮罩。

### 3.2 下载完整高清导图

推荐提供两种文件：

- **PNG 高清图片**：普通导图优先按排版尺寸的 3 倍输出；较大导图使用 2 倍并标明实际像素。白底、中文字体、完整边距，根据内容尺寸而非当前窗口大小生成。
- **SVG 矢量图片**：保存完整布局和可缩放文字，适合大导图、打印及继续放大查看。

使用整棵树独立计算导出布局，展开所有分支，按实际文字宽度换行并增加节点高度。所有章节和知识点都必须输出完整文字，无省略号，无视口裁切，不改变用户正在浏览的导图状态。

2026-10-06 用户确认样式：**保留向右单侧展开，按内容自动调整节点宽度**。页面与完整导出共用布局模块，测量实际字体宽度，短知识点优先单行，长文本达到最大宽度后换行；节点高度按行数计算，知识点间距缩至 12px、章节间距 24px。页面使用 14px 文字，知识点宽度 240～620px；完整导出使用 16px 文字，知识点宽度 240～880px。主题与章节使用较粗字重及浅色背景，所有节点按子树高度安排，确保分支和卡片不重叠。

页面知识点预览最多四行，完整原文仍可通过节点详情和悬停查看；PNG／SVG 输出全部文字，不受预览行数或折叠状态限制。实际 4 条已有记录的排版高度减少约 47%～50%，详见测试报告。

导出前等待字体可用；明确处理生成失败。PNG 单边最多 16,384 像素、总量最多 32,000,000 像素，依次选择 3 倍或 2 倍；两档均超出预算时提示使用完整 SVG，不静默截断或以模糊小图冒充高清。实际输出尺寸见测试报告。

文件名使用视频标题，并去除文件系统不接受的字符。图中保留视频标题；不包含账户信息、Cookie 或模型密钥。整个导出在本机浏览器完成，不发送内容到图片服务，不产生新的模型调用。

### 3.3 单独下载字幕

推荐在“字幕原文”页提供直观的“下载字幕”操作及格式选择：

- **SRT**：字幕序号、起止时间和原文，适合播放器和剪辑工具。
- **TXT**：带时间戳的完整原文，适合直接阅读、复制给 AI 或自行整理笔记。

沿用现有导出接口，新增 `format=txt`，继续支持 `markdown` 和 `srt`。下载从后端读取完整字幕记录，原语言、原文字和时间顺序保持一致；文件名包含视频标题与字幕语言，使用 UTF-8。

取得字幕后即可下载，不要求生成摘要，也不要求配置 DeepSeek。字幕不存在或获取失败时提供准确提示；没有字幕的平台继续沿用当前处理规则。

已确认的入口范围：“学习工作区 → 获取字幕 → 字幕原文 → 下载字幕”，独立于 AI 总结；本次没有新增首页字幕任务流程。

6. 更新项目总结与测试报告，提供本机验收方式，请用户检查阅读体验和文件效果。

优先复用现有 Vue/SVG 和浏览器能力；目前没有必须引入新导图库或图片服务的理由。视频解析、下载任务、B 站/芒果适配和模型协议均不需要修改。

## 5. 自主验收标准

| 验收项 | 检查内容 |
| --- | --- |
| 全屏 | 按钮进入和退出、Escape、重复操作、焦点恢复、画布尺寸变化、全屏不可用时回退 |
| 阅读 | 缩放、拖动、滚轮移动／缩放、折叠、列表、长文字详情、字幕定位；首次展开不自动缩小 |
| 移动端 | 窄屏入口与退出可见，工具栏可操作，页面无横向溢出 |
| 图片完整性 | 浏览器中折叠或移出视口的章节仍在导出中；长中文、英文、特殊字符全部保留 |
| 高清与边界 | 检查实际 PNG 像素尺寸、文字清晰度、首尾边界；SVG 节点数及文字与完整数据一致 |
| 超大导图 | 超限提示准确，SVG 仍完整；失败可重试，不留下下载忙碌状态 |
| 字幕完整性 | 搜索后或第二页下载，文件仍含首尾全部字幕；语言、时间戳、中文编码正确 |
| 独立字幕下载 | 没有摘要、没有模型密钥时成功；字幕失败和已删除记录返回明确错误 |
| 原功能回归 | 视频解析和下载、摘要引用、字幕分页和搜索、问答、历史与删除继续通过 |
