# 视频解析、下载与 AI 总结同屏方案

日期：2026-10-07。状态：**用户已确认推荐方案，开发与自动验证已完成，等待人工验收。**

本次目标：用户点击一次“解析视频”，即可在同一页面查看视频信息、选择下载格式，并在条件满足时自动获得视频总结。参考用户提供的左右布局，沿用项目已有功能和视觉语言。

## 1. 当前项目分析

以当前工作目录的代码为准，结合 docs 中的总体文档、下载和平台适配方案、AI 学习方案、导出扩展方案、问答/摘要 SSE 报告及草稿撤回修复报告。旧文档里“独立学习工作区”和“手动生成”的描述属于已有版本，本次方案提出改变这两项交互，须经本次用户确认。

| 模块 | 当前代码事实 | 本次处理 |
| --- | --- | --- |
| `frontend/src/App.vue` | 首页解析 `POST /api/v1/parse`，成功后自动打开下载结果弹窗；学习区通过 `#learn` 切换 | 统一页面入口和当前视频状态，在页内呈现结果 |
| `components/VideoResult.vue`、`FormatPicker.vue`、`DownloadAction.vue` | 提供封面/标题、格式选择、下载方式、任务进度和文件入口 | 复用业务契约，增加适用于窄左栏的紧凑展示 |
| `learning/LearningWorkspace.vue` | 创建字幕记录和生成总结是两个操作；包含记录恢复、四类内容、SSE 订阅、导出和删除 | 拆分页面外壳与内容，嵌入右栏，统一当前记录 |
| `learning/summaryDraft.ts`、`chatStream.ts` | 草稿按阶段/尝试保留；支持 UTF-8 SSE、断流恢复；完成时优先接收正式结果 | 保留已有行为，并回归此前撤回/并行读取修复 |
| `learning/MindMapView.vue`、导图布局和导出模块 | 导图与摘要同源，支持全屏、滚轮、折叠、原文定位、完整 PNG/SVG | 复用；右栏尺寸变化后适配画布，原文定位仍在右栏内完成 |
| `backend/app/main.py`、`video_service.py` | 解析和下载是独立 API；下载任务位于内存，文件任务有效期两小时 | 继续按原格式和交付方式下载，不要求等待总结 |
| `analysis_routes.py`、`analysis_jobs.py` | 字幕、摘要和问答各有后台任务；活动任务去重；现有 `POST /analyses` 不生成摘要 | 增加显式选择的“获取字幕后自动总结”任务编排 |
| `analysis_store.py` | SQLite 保存字幕、摘要、问答、分段缓存、任务和用量；启动将未完成任务标为中断 | 保存自动链路的待执行状态，沿用中断需手动重试规则 |
| `subtitle_service.py` | 仅尝试 B 站/抖音/YouTube 字幕；分 P 和语言参与身份；下载与字幕使用不同会话路径 | 按后台实际能力判断是否可总结；字幕与下载权限分别处理 |
| `summary_service.py`、`deepseek_client.py` | 全字幕分段/逐层汇总，缓存与结构/引用校验；摘要 4096 tokens，明确截断的一次修复可提高至 8192 | 沿用当前生成逻辑、模型与额度，不增加新的摘要提示词或模型服务 |

关键结论：这次是页面整合与操作链路改造。视频能够解析/下载，并不意味着字幕可以获取；芒果及其他下载来源目前没有 AI 字幕适配。学习记录没有持久化封面和下载格式，打开旧记录时应先显示已保存内容，另行解析下载信息，不能为了补封面而重新生成摘要。

当前工作目录有既有未提交修改，以及文档移至 docs 的变化。实施时以这些现有文件为基础，不重置或覆盖其内容。

## 2. 推荐页面

推荐采用**页面内双栏工作区**，替代下载结果弹窗与独立学习页面之间的来回切换。

```text
SaveAny                                         学习记录 / 使用帮助
视频链接 [                                      ] [解析视频]
[✓ 自动总结]  有可用字幕且已配置模型时调用 DeepSeek

┌ 视频信息与下载（约 320px） ┐  ┌ 摘要 / 字幕原文 / 思维导图 / 视频问答 ┐
│ 封面、标题、平台、时长    │  │ 当前阶段或失败原因                   │
│ 打开原视频               │  │ 一句话概览、简明总览                 │
│ 格式选择、下载选项       │  │ 章节大纲、知识点、原文引用           │
│ 下载按钮、进度、保存入口 │  │ 长内容在右栏滚动                     │
└──────────────────────────┘  └──────────────────────────────────────┘
```

- 初始页仍以链接输入和简短指引为主；有结果后收紧顶部，主要空间给双栏结果。
- 桌面宽度达到 1024px 后左右排列，左栏约 300～340px，右栏使用剩余宽度；整体最大宽度约 1280px，主体间距 16～24px。
- 左栏封面在上，标题和时长在下；格式选项采用紧凑选择器，保留真实格式 ID、分辨率、音频合并提示及已知大小。下载高级选项折叠，下载状态留在同一栏。
- 右栏默认显示摘要，四类内容共享同一视频身份；复制、导出、重试/重新生成放在对应内容旁。状态文案用真实阶段，不模拟百分比。
- 学习记录改为按需打开的抽屉，避免常驻第三栏占用阅读空间；仍保留分页、新建、删除确认与恢复。
- 手机/较窄平板使用上下布局，信息卡收紧、下载选项可折叠，摘要紧随其后；允许自然纵向滚动，保持触摸与键盘操作。
- “同屏”验收指桌面首屏同时可见视频标题/时长、主要下载操作和摘要总览/生成状态。长视频所有章节仍需滚动阅读，不通过缩小文字挤进一屏。
- 当前文件下载期间，沿用单视频任务约束，暂禁用更换链接及会更换当前视频的记录操作；摘要阅读、标签切换和当前视频问答仍可使用。

可选方案：保留首页，将原结果弹窗扩大为双栏弹窗。它也能实现同屏，但长内容阅读和移动端操作空间更有限；建议优先页内方案。

## 3. 推荐自动总结规则（待确认）

1. 输入框旁提供“自动总结”开关，推荐默认开启并记住本机偏好；点击解析时固定本次选择。开关只决定下一次解析，不表示取消正在执行的任务。
2. 先解析视频信息，成功后立即显示左栏；随后创建/复用字幕记录。已开启自动总结且字幕有效、模型可用时，后端自动接续原有流式摘要任务，无需第二次点击。
3. 自动链路在后端接续，使网页刷新/关闭后仍可完成已经提交的字幕与总结流程；前端只订阅/读取状态。关闭网页不能取消模型请求，服务进程停止则中断，重启后等待用户手动继续。
4. 已有成功摘要先展示并复用；已有活动任务接回同一任务。刷新、历史打开、页签切换、订阅重连、同一视频的重复解析均不创建重复付费任务。
5. 已有失败/中断记录显示原因及“重试总结”，等待用户点击；不因重新打开页面而重新计费。用户主动“重新生成”才强制创建新版本，生成失败仍保留此前成功版本。
6. 无字幕、字幕访问受阻、超过学习上限、平台不在学习范围、未配置模型等情况，在右栏说明原因和可执行操作；左栏下载继续可用。解析本身失败时不启动新的自动学习链路。
7. 关闭自动总结后仍可获取/查看/下载字幕，模型由用户手动点击生成。切换字幕语言只获取对应语言版本，已有内容可读，新版本摘要由用户手动生成，避免额外隐式调用。
8. 保留中文总结、字幕原语言、最长两小时等已有边界。问答继续由用户提问触发；导图继续由同一正式摘要生成，不另发模型请求。

正常新视频流程为：**解析信息 → 展示下载卡 → 获取字幕 → 自动生成流式草稿 → 校验保存摘要与导图**。下载可在字幕/摘要仍处理中独立开始。

## 4. 接入设计

### 前端

- 抽取下载状态与学习状态的可复用逻辑，减少 `App.vue` 和 `LearningWorkspace.vue` 双重 URL/页面状态。
- 统一工作区持有输入 URL、已提交 URL、解析结果、记录 ID 和下载任务所属 URL；仅编辑输入框不改变已展示视频。使用 AbortController 与请求序号，丢弃旧视频的迟到响应。
- 将下载结果/状态和学习内容分为两个展示组件。保留已有四页内容、草稿处理、引用定位和导出模块。
- 保留旧 `#learn` / `#learn/{id}` 链接的打开和浏览器前进/后退恢复；其内容在统一工作区内显示。恢复记录时只读取已有学习结果，必要的下载格式解析使用 `auto_summary=false`，不触发模型。
- 采用真实主机名/后端能力判断学习范围，不只匹配标题或 extractor 字符串。
- 模型配置或后端版本不兼容时保留视频下载和已有结果阅读，并说明需要的配置/重启操作。

### 后端

- 为 `AnalysisCreate` 增加可选 `auto_summary: bool = false`；旧请求继续只获取字幕。自动链路使用现有 SSE 摘要能力。
- 自动总结请求登记为可查询的待执行任务/意图；字幕保存成功后在受控锁/事务中交接到已有 `start_summary` 流程。等待字幕期间不占用线程阻塞等待，保持原线程池/队列上限。
- 用当前记录和活动作业去重；已保存摘要直接复用，配置变化不导致读取旧结果时静默重新生成。任务失败、中断和删除使相应自动意图终止。
- 字幕失败与摘要失败分开更新，自动接续出错不把已获取字幕标记为失败；提交重复请求、删除与任务交接的并发需要测试。
- 延续本机 Host/Origin 检查、用量统计、分段缓存、引用校验和重启中断规则。能力接口增加版本标识，使新页面能判断运行中的后端是否支持自动接续。
- 存储新增状态若需要 schema 升级，提供旧库升级和已有记录读取测试；先使用数据库副本验证，保留本机数据。

## 8. 实施结果

采用页内工作区：`LearningWorkspace.vue` 管理当前视频与学习记录，下载状态抽出至 `useVideoDownload.ts`；`CompactVideoResult.vue` 提供紧凑信息栏，下载操作固定在栏底。原摘要、字幕、导图、问答和导出逻辑保留。历史抽屉使用原生 dialog，关闭时立即解除页面交互限制。

自动接续以现有 jobs 表中的 `auto_summary` 作业持久化；字幕作业释放队列槽后启动流式摘要，等待期间不占用工作线程。无需数据库迁移。`POST /analyses` 新增可选 `auto_summary`，默认 false；公开配置新增 `auto_summary_version: 1`。
