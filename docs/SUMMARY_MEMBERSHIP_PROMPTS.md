# AI 总结的登录与会员弹窗

更新日期：2026-10-08。用户要求：未登录尝试 AI 解析时弹出登录窗口，次数用尽仍尝试时弹出会员窗口。本轮已实现并完成自动验证，人工验收待确认。

## 当前行为

- 新 AI 总结被服务端以 `LOGIN_REQUIRED` 拒绝时，打开登录窗，并在表单上方显示原因。已有过期账号缓存也切回登录表单，迟到的旧状态响应不能恢复失效缓存。
- 服务端返回 `QUOTA_EXCEEDED` 时，打开账号与会员窗口，在顶部显示额度用尽提示，读取当前额度并显示免费／VIP 方案。进入窗口不创建付款订单，购买仍需要用户点击原购买按钮；有效期内禁止重复购买。
- 覆盖解析后自动总结，以及手动生成、重新生成、重试总结。自动流程根据当前后台任务的结构化错误处理；同一次尝试只弹一次，关闭窗口或刷新、打开历史不会反复弹窗。重新明确点击解析或重试时，可再次提示。
- 关闭自动总结后只获取视频信息／字幕，下载、已有摘要复用和导出不触发上述弹窗。其他模型或网络错误继续显示原错误，不通过错误文字猜测是否需要登录。
- 登录或开通后可关闭窗口，再点击“生成总结／重试总结”。本轮不增加自动重新调用模型的行为，也不改变价格、额度、结算或退款规则。

## 修改入口

| 文件 | 作用 |
| --- | --- |
| `frontend/src/learning/api.ts` | 在保留错误说明的同时提供错误类型和 HTTP 状态 |

| `frontend/src/membership/MemberPanel.vue` | 提供登录／会员窗口入口，显示触发原因，登录成功清除旧提示 |
| `frontend/tests/summary-membership-prompts-e2e.cjs` | 新增弹窗、额度、缓存、历史及购买触发边界验证 |

后端和原 API 请求参数保持不变；服务端仍负责真实登录和摘要额度校验，前端弹窗没有代替服务端限制。

## 人工验收

原地址 `http://127.0.0.1:8000/` 按 Ctrl+F5 刷新：

1. 退出登录，保留“解析后自动总结”开启，解析有可用字幕的视频；自动总结被拒绝后出现登录窗。关闭后仍可下载，点击重试再次打开登录窗。
2. 登录额度已用完的账号，尝试新总结或重新生成；打开会员窗口，显示用尽原因、当前额度与原会员方案。
3. 关闭窗口后刷新或打开历史，不应自行重复弹出。读取已有摘要或关闭自动总结只取字幕，不应因为登录／额度弹窗中断阅读和下载。

自动验证已通过，人工体验仍待用户确认。
